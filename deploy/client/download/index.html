Install the dbt Portal

Download, double-click, done. About five minutes, and the portal opens in your browser.

Before you start

  • Docker Desktop (or Podman) installed. The installer starts it if it is not running.
  • The access token you were sent. It only lets this computer download the portal.

Windows

Paste your token here and the installer you download already has it. Or leave it empty and paste it in the installer.

The token stays on this computer: it is written into the file you download, never sent anywhere.
Downloaded
  1. Open Install-DbtPortal.cmd from your downloads.
  2. If Windows says it protected your PC, click More info, then Run anyway.
  3. Choose where your dbt project is (a Git repository, or a folder on this computer) and click Install.

The window shows each step, then opens the portal and gives you the admin password. A dbt Portal shortcut is added to your desktop.

macOS / Linux

Open a terminal, paste this, press Enter. It asks the rest.
