Install the dbt Portal

One command. About five minutes. The portal opens in your browser and walks you through the rest.

1

Have these ready

  • Docker Desktop (or Podman) installed and running. Nothing else: no Python, Node or dbt.
  • The access token you were sent. It only lets this machine download the portal.
2

Paste your token, copy the command

The token stays in this page: it is only put into the command below, never sent anywhere.

My dbt project is a folder on this machine (optional)
Leave empty to connect a Git repository inside the portal instead (recommended).

      

        
        Copied
      

      

        Open PowerShell, paste, press Enter.
        Open a terminal, paste, press Enter.
      

    

  


  

    
3

      
Then it happens on its own

      
    
        
  • Checks your machine and signs in to the image registry with your token.
    • 
        
  • Downloads and starts the portal, then opens it in your browser.
    • 
        
  • The Setup Assistant takes over: workspace name, warehouse connection, your dbt project (Git or a folder), packages, reports and your team.
    • 
      

    

  


  
Trouble? Run .\manage.ps1 doctor (Windows) or ./manage.sh doctor in the install folder, ~/dbt-portal by default.
